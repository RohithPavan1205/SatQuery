# SatQuery AI — An Interactive Vision-Language Assistant for Multimodal Remote Sensing Image Analysis through Text Queries

SatQuery AI is an agent/controller-based multimodal remote-sensing analysis system designed to interactively answer questions and analyze satellite imagery using natural language. 

## Planned Capabilities
- **Visual Question Answering**: Query satellite images using natural text.
- **Image Captioning**: Generate descriptive captions for remote sensing imagery.
- **Grounding/Spatial Evidence**: Localize features mentioned in queries or captions within the image.
- **Change Detection**: Identify structural and environmental changes across temporal image pairs.
- **Optical-SAR Fusion**: Combine optical and synthetic aperture radar data for comprehensive analysis.

*Note: SatQuery AI is currently in its initial development stage (September Phase-1). None of the capabilities listed above are implemented yet.*
