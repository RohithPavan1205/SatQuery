# Datasets

This directory manages dataset configuration and metadata for SatQuery AI.

## Planned Dataset Organization

**Mandatory datasets:**
- BigEarthNet.txt
- RSVQA
- VRSBench
- CDVQA

**Supplementary datasets:**
- SEN12-FLOOD
- STURM-Flood
- BigEarthNet-MM

*(Note: Datasets are not downloaded or included directly in this repository.)*

Dataset files, large imagery, and raw data should be excluded from version control through the root `.gitignore`. This directory is intended only for scripts, metadata, and configuration relating to datasets.
